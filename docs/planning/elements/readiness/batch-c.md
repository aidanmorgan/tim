## 3. Decisions recorded

**Owner decisions, 22 November 2026, applied.**

- Ropes are solid (decision 1). The delivered rope is drawn with no collider: a recorded visible-solid defect owned by `ENGINE-CONNECTION-MATERIALS`. No Batch C spec calls a rope a non-solid strand.
- The engine programme comes first (decisions 3 and 3a). Every Batch C spec says it is blocked on the engine programme and names its stories with 3a's names: `ENGINE-SPATIAL-QUERIES`, `ENGINE-ISLANDS-SLEEP`, `ENGINE-SUPPLY-DEMAND` (sprint key `engine-supply-drive-demand`), `ENGINE-CAPABILITY-INSTANCES`, `ENGINE-JOINT-KINDS`, `ENGINE-PARAMETER-BOUND-FRAMES`, `ENGINE-COMPLIANT-FRICTION`, `ENGINE-TENSILE-EXTENSIONS`, with the existing `ENGINE-OPTICAL`, `ENGINE-GOALS` and `ENGINE-CONNECTION-MATERIALS`. No spec says a part sleeps: island sleeping is not implemented and a resting body is still stepped (`ENGINE-ISLANDS-SLEEP`).
- The Powered gate's and Beam shutter's blade spring gets a declared rest position so an unpowered blade closes in every orientation; tests cover upright, on its side and inverted (decision 6). The rest position belongs to `ENGINE-JOINT-KINDS` (coordinator decision 21): the rest coordinate may lie outside travel (a preload), `SliderTravel` admits it, and the starting offset stays a separate value. Worked value in both specs: rest 0.85 m below closed at 14 N/m gives 11.9 N of closing preload against the blade's 9.81 N weight; full-open load upright is 43.4 N (gate) and 38.5 N (shutter), inside the 60 N drive.
- Gear ratios follow tooth counts (decision 8): CAT-057 says so; its two equal wheels give −1.
- One receiver law and the optical conventions (decision 9; coordinator decisions 16 and 21): CAT-007 cites [EL-176](../EL-176-red-laser-emitter.md) section 10 instead of restating optical rules, and CAT-007 and CAT-051 use the one optical tolerance set (±2 % power, 1 s guard, 0.5° direction, ±0.02 m end points).
- Run length (decisions 13 and 17): 30 s is the default, not "the run limit" (CAT-034); the maximum is 300 s. No Batch C row runs longer than 30 s, so none needs `ENGINE-RUN-LENGTH`.
- Delivered mechanical connections stay rigid (decision 2): CAT-019 and CAT-057 say so.
