### Behaviour and numbers (shared acoustic laws)

All values are f32. Level is dimensionless in [0, 1]; distance in metres; time in seconds of game time ([D10](../invest/delivery-batches.md#3-family-level-decisions)); tone is the closed enum `ToneBand`.

| # | Law | Reason for the numbers |
| --- | --- | --- |
| L1 | An **emission occurrence** has origin, axis, pattern (Cone with half-angle 35°, or Omnidirectional), tone, strength s ∈ (0, 1] and a kind: **Pulse** (local duration 0.15 s) or **Sustained** (one occurrence from start until stop; [D17](../invest/delivery-batches.md#3-family-level-decisions)). | 0.15 s is long enough to see a ring leave the mouth and short enough for five pulses a second. A sustained source is never back-to-back pulses, which would retrigger pulse listeners. |
| L2 | Sound travels at 12 m/s to a range of 8 m. A receiver at distance d hears a pulse from d/12 s after emission for 0.15 s, and a sustained occurrence from start + d/12 until stop + d/12. | 12 m/s equals the Fan's reference flow speed (`elements/Fan/FanElementDeclaration.cs:48`), so the delay across a 6 m bench is a visible half second. |
| L3 | Level = s / (1 + 0.08·d²) for d ≤ 8 m, inside the cone and with an unoccluded straight path; otherwise 0. | A default meter (threshold 0.25) hears a full-strength source out to 6.1 m (level 0.25 at d = 6.12 m); the most sensitive meter (0.05) hears it to the 8 m range (0.163). |
| L4 | A receiver's level is the **strongest** admissible arrival, never a sum; a source never hears itself. | Decided under the standing delegation (formerly S530): no interference claim, and two sources can never exceed level 1 (A10). |
| L5 | A receiver declares a band mask. An arrival outside the mask contributes exactly 0. | The requirement outcome: an equal-strength wrong-tone pulse reads 0 at every threshold. |
| L6 | Solid colliders occlude: an opaque collider on the straight path removes the arrival; a collider with a declared transmission factor ([EL-050](EL-050-acoustic-screen.md)) multiplies it. The emitter's and receiver's own colliders are exempt. | "Visible = solid" also means visible = sound-blocking, so players can predict it. |
| L7 | **Tick order ([D7](../invest/delivery-batches.md#3-family-level-decisions)).** Acoustic emission, propagation and reception run in the acoustic phase of the [combined tick order](EL-176-red-laser-emitter.md#combined-tick-order) (optical convention 4, step 1, with the levels committing together at its step 5), which this row cites and does not restate. A threshold node samples the committed level on the next tick's signal evaluation, beside the delivered oscillators; the pulse it emits is routed to its targets in that same tick (`engine/gpu/ActivationNetwork.cs:505`–`:512`), and a supply contact that follows the node's state passes supply from the next electrical solve after that. So a meter's pulse leaves one tick (dt, 1/120 s by default) after the sound arrives and its contact conducts one solve later. | One-way data flow; no lesson times a single tick. |

**This element.** Band level = L4 restricted by L5. A rising crossing of `threshold` emits one `ActivationOut` pulse only if `PowerIn` is supplied on that tick; an unpowered crossing is discarded and never replayed (`parts/SoundMeterPart.cs@a6c914e:L72-L83`). The 0.9 hysteresis leaves a band 0.025 wide at the default threshold, which stops chatter as a pulse's level steps on and off. Consistency: fed by the Battery's default 120 W limit it draws nothing itself; its `Supply` output can carry the default Motor or Fan load because the contact adds no limit of its own.

### Engine conformance (22 November 2026)

Checked against the owner's engine-conformance instruction of 22 November 2026, `_bmad/custom/element-free-engine-design.md`, `docs/gpu-f32-physics.md` and `docs/architecture/element-package-isolation.md`. The same seven points are answered in every sound spec.

1. **Declaration data only.** The package is a scene, a declaration and bindings: one acoustic receiver with a band mask, one threshold signal node, one supply contact and three ports. It has no solver, update loop, callback or state machine, and no engine code may branch on `tuned_sound_meter`. "Off-band reads 0" is the receiver's declared mask applied by the engine's one reception rule, not a filter inside the part.
2. **Generic laws.** Reception: L2–L6 (travel, falloff, strongest arrival, band mask, occlusion) over all declared emitters and receivers. Trigger: a threshold signal node with declared on and off levels (N4, the threshold row of `ENGINE-SIGNAL-NODES`). Power: the supply network's contact rule (C2). `band` and `threshold` are the only values that parameterise them.
3. **Three layers.** *Colliders:* cabinet box, foot box, two prong boxes and three socket spheres on one static body with the static default material; physics reads no art. *Visuals:* the art table above; no art mesh is a collider. *Animation:* read-only presentation bindings. Moved by a binding: `Needle` (rotation), `Lamp` (colour), `Bars_Low`/`Bars_Mid`/`Bars_High` (visibility). Moved by nothing: `Cabinet`, `Foot`, `Fork`, `Dial`, port spheres (they sit at the static body's pose).
4. **One-way flow and typing.** Committed receiver level → signal node → presentation; nothing returns to physics. `band` is the enum `ToneBand`; ports are `PortId` and `PortRole`; every value is f32.
5. **Flat state.** 1 static body; 7 colliders (4 box, 3 sphere); 0 joints; 0 drives; 0 sensors; domain nodes: 1 acoustic receiver, 1 threshold signal node, 1 electrical node with 1 contact; 0 stores; 7 presentation bindings (needle, three lamp colour channels, three bar visibilities). All counts are fixed at compile time.
6. **Performance fitness.** 7 colliders against the Impact switch's 5 (`elements/ImpactSwitch/switch.tscn`): the two extra are the fork prongs, proud solids that must collide (visible = solid) and are the shape cue against the plain meter. The body is static and joins no island. The receiver is one point, bounded by each emitter's declared 8 m range. **Bounds (Story 14.0, design contract D5; text agreed with Batch D):** occurrences in flight per emitter are bounded by its declared minimum interval and lifetime; emitter, receiver and occurrence tables are sized at Run from the compiled declarations, with no fixed scene ceiling; per tick, reception work is proportional to occurrences whose wavefront covers a receiver within the declared range, found through `ENGINE-SPATIAL-QUERIES`, never emitters × receivers of the whole scene. Occlusion tests use the same query interface. This spec invents no number.
7. **Scenarios.** Rows 1–9 place parts through the production edit interface and run the real simulation; none depends on a code path that names this package.
