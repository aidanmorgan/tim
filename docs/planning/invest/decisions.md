# Bounded model decisions inside existing owners

These questions are not new work IDs or a demand to reopen settled contracts. Reuse an applicable independently reviewed answer; otherwise select exactly one question and its finite input/control oracle. Stop with the adopted/rejected model, units/ranges/tolerances and independent expected result, or an explicit unresolved conflict that blocks the named next implementation. A diagnostic does not pass runtime acceptance. Fixed target ownership and source choices cannot be waived; no part-local solver, old-format support or parallel model path. Each decision is a supporting design criterion of its same functional owner, with stable pair and required-stage review.
