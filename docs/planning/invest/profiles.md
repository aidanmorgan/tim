# Family contract boundaries

**Current architecture:** [Canonical Half game values and WGSL f16 physics](../../gpu-f16-physics.md) define the numerical model. Current design/acceptance is self-contained; implementation and qualification status are in [TODO](../../../TODO.md).

These are reusable constraints, not INVEST scores or evidence of completion. Read the exact source body and selected child card; fixed architecture, all original criteria and engine-first/per-element publication gates are non-negotiable. Unresolved models get a bounded decision for one named law/element, followed by the named implementation; do not start an arbitrary redesign.

<a id="mechanics"></a>
## mechanics

**Independent/value/small boundary:** One declared geometry/load law or element; current source specifies finite stores, contacts and ports.

**Negotiable:** Choose specialized solver/declaration details; cannot substitute named-part scripts for generic authority.

**Estimable scope and uncertainty:** Measure/capture its declared load range; unresolved geometry/model question ends in one reviewed oracle before its named implementation.

**Observable proof:** Independent force/work/geometry oracle; positive loaded behavior, separated/slack/exhausted control and exact threshold/Reset/save.

<a id="fluids"></a>
## fluids

**Independent/value/small boundary:** One named open-water transport/storage/converter, with each physical shape/mode separately visible.

**Negotiable:** Choose bounded discretization preserving mass/species/energy; no animation-only fluid authority.

**Estimable scope and uncertainty:** Finite capacity, pressure/head and moving-container coupling bound the closure; kernel and actual GPU qualification precedes product part.

**Observable proof:** Empty supply, overflow, reverse/head/boundary, spill/leak and mass/work conservation; actual UI connections and restoration.

<a id="pneumatics"></a>
## pneumatics

**Independent/value/small boundary:** One sealed-gas storage/valve/actuator outcome; do not treat open airflow as the same model.

**Negotiable:** Choose state representation under declared gas law; pressure is not an unlimited force selector.

**Estimable scope and uncertainty:** Inventory pressure, volume, temperature, return path and supply; an unresolved law is a bounded model decision, not indefinite deferral.

**Observable proof:** Zero/depleted pressure, closed/open valve, blocked load, expansion/compression/return and finite work; Reset/save exact.

<a id="electrical"></a>
## electrical

**Independent/value/small boundary:** One finite source/load/converter or one typed logical operator.

**Negotiable:** Topology algorithm may vary; power/control remain different domains and all fixed modes stay enums.

**Estimable scope and uncertainty:** Identify affected graph/SCC and timed propagation boundary; current Both is existing AND, never add an alias.

**Observable proof:** All truth-table rows, fan-out/reconvergence and supported monotone cycles; reject unsupported zero-delay nonmonotone cycles; no power from true signal.

<a id="optical"></a>
## optical

**Independent/value/small boundary:** One optical source/transport/filter/receiver/converter or explicit logic operation/channel.

**Negotiable:** Choose coherent transport details within finite per-channel ledger and fixed A/B/carrier contract.

**Estimable scope and uncertainty:** Freeze aperture, moving occlusion, channel and supply boundaries; no broad all-optics story.

**Observable proof:** No-light/no-carrier and wrong-channel controls; opaque/transparent/hollow intervals; shared source cannot duplicate energy; each channel/operator separately.

<a id="acoustic"></a>
## acoustic

**Independent/value/small boundary:** One source, route, resonance or receiver outcome with declared event/time identity.

**Negotiable:** Transport implementation negotiable after strongest-arrival versus additive-intensity decision; never silently implement both.

**Estimable scope and uncertainty:** Bound source supply, tone band, delay, route/loop and overlap; continuous and rising-pulse speaker are distinct.

**Observable proof:** Silence/wrong tone/no power, delayed arrival, duplicate/loop rejection; bell/chime actual contact not mere overlapping volume; each tone.

<a id="thermal"></a>
## thermal

**Independent/value/small boundary:** One heat/phase/reaction/conversion law or individually named TH element.

**Negotiable:** Numerical integration may vary inside conservation, latent heat and irreversible-in-Run requirements.

**Estimable scope and uncertainty:** Specify finite material/energy/oxidizer/stores and supported phase boundary before implementing named consumer.

**Observable proof:** No source/below threshold, phase/reaction onset and exhausted supply; energy/species balance, rollback, Reset/save, independent heat/work oracle.

<a id="radiation"></a>
## radiation

**Independent/value/small boundary:** One adopted particle group/source/shield/instrument/converter outcome.

**Negotiable:** Use frozen grouped fictional model, not unreviewed extra UV/radio alternatives.

**Estimable scope and uncertainty:** Bound source activity, group/material, path length, rate/dose and irreversible state; model unknown goes to S604 then named law.

**Observable proof:** Missing-source invalidity, shield gap/material/thickness, trajectory dose versus rate, decay half-life, fast/slow neutron conversion and energy accounting.

<a id="structure-material"></a>
## structure-material

**Independent/value/small boundary:** One structure, failure mode, granular/material operation or environment preset.

**Negotiable:** Choose deterministic representation within target generic laws; no magic part-name behavior.

**Estimable scope and uncertainty:** A decision must settle explicit sensing/strength/fragment bounds or programmable presets, then its same named element implements it.

**Observable proof:** Below/above threshold, unsupported preset rejection, bounded fragments/material conservation, geometry/contact and Reset/save.

**Negotiable:** Interaction design negotiable inside actual UI, typed input, palette and lifecycle rules.

**Observable proof:** Actual gesture succeeds; invalid/cancelled/stale/edge action leaves state usable; exact construction and save/Reset where applicable.

<a id="campaign"></a>
## campaign

**Independent/value/small boundary:** One level's taught causal objective after its part/mode has shipped.

**Negotiable:** Puzzle layout/allowed alternatives negotiable; all150slots and required teaching/prerequisites fixed.

**Estimable scope and uncertainty:** Bind exact named level/first-use/modes, control and uncertainty from human attempts; density is unqualified until tested.

**Observable proof:** Real UI solution plus meaningful failure/control, alternative where required, exact Reset/save; independent human clarity separately from reference success.

<a id="engine"></a>
## engine

**Independent/value/small boundary:** One numerical/state/transport/presentation invariant in its target sole owner.

**Negotiable:** Specialized implementation negotiable; no fallback, aliases, dual ownership, migration flags or magical strings.

**Estimable scope and uncertainty:** Inspect direct/transitive current callers, shared stores and clocks; bounded failure/question first, no speculative rewrite.

**Observable proof:** Independent numerical or protocol positive/control/boundary with rollback; stage-specific Chrome/build/lifecycle/performance retained.

Every part/mode proof uses actual Chrome UI placement and controls, intended behavior plus meaningful negative/control, real typed connections, exact Run/Reset construction restoration, applicable save and production build. Native or fake-page tests supplement it. Future finite modes remain obligations even when the current manifest does not yet list them. No current Configuration=Fixed placeholder certifies absence of other source-required modes.

Existing-part vertical staging: a required law/kernel control is proved inside its named existing UI consumer before that slice passes. No full law-family/native audit precedes every UI interaction. New product-part expansion still waits for P0-035, while generic placeable fixtures prove unshipped required laws at their engine qualification stage. The current register, not historical horizontal order, determines external completion dependencies.
