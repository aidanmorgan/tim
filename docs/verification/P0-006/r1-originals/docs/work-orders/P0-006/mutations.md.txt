## State that must not be confused

There is no current solver body free list: _objects is fixed and _objectIndices immutable
for a world. A future internal compacted pool must restore its free order/versions exactly and
remain hidden behind stable IDs. AnimationBatch and SceneAnimationAdapter do have explicit free
arrays/version counters; preserve them in registration rollback. Failed local slot allocation may
restore its slot version; an attempted external instance ID is still burned, preventing delayed
traffic alias. Existing committed removal followed by slot reuse never revives the old handle.

Source search over production engine/parts/ui found no System.Random, RandomNumberGenerator,
GD.Rand*, or RNG state used in authoritative stepping. Therefore current RNG checkpoint set is
empty, not an omitted requirement. RuntimeSession secure identity generation is external identity,
not physical randomness. If a named future law introduces RNG, its typed algorithm ID and complete
state/stream/draw count become owned transaction/replay state before that law can pass; seeded
reinitialization on rollback is forbidden. Test-only random fixtures are not runtime RNG ownership.

A restoration comparison has three explicit sets:
AuthorityExact includes all Core state, topology/identity maps, canonical order, pending physical
work, tick/revision and committed producer state. OwnerResourcesExact includes live participant/
binding/lease registrations and allocation/free-list ownership, including no leaked failed candidate.
DiagnosticsAppendOnly retains error/high-water/attempt information and may increase on a failure;
it must not influence physical replay. Raw unused scratch bytes are not authority, but any retained
reference/slot/cursor that can affect later behavior belongs to one of the first two sets.
No epsilon for either exact set. Process death is a separate Indeterminate outcome, not rollback.

All topology/capability changes reserve publication membership and byte size before committing.
Required output unable to fit means no commit, never a successful mutation followed by silent drop.
Callbacks/serialization/resource disposal after authority commit are recipient work with their own
explicit failure result. This inventory does not certify the current MachineWorld participant list.
