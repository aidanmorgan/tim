## Finite current mode closure

The current parameter enum families are enumerated in identity.md, not inferred from display names.
Resource files and P0-002's catalogue mode ledger retain all72 definitions and104 configuration/mode
records; overlapping scripts are not deduplicated into one element. The input closure includes
their enum declarations, resource defaults and validation consumers. Current generic enum reads
use CannonPhase; generic future enum channels require explicit typed member/schema mappings,
not arbitrary System.Type names crossing a worker. Closed message/role/phase/schedule enums in
the fixture tool remain typed through fields, collections, comparisons and tests. Raw JSON field
names and intentionally unsupported numbers appear only in the negative external-schema fixtures.

Current construction string/property/resource boundaries remain known migration work, not an
exception that makes them compliant. This Design row does not prematurely replace one caller
and leave active content on a second supported path. P0-008/016 and the typed consumer children
must forward-replace the complete actual chain together.
