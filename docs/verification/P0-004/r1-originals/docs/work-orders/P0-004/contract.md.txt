## Required deliverable and boundary

Freeze the assembly dependency graph, instance ownership, field/property/caller migration map,
single authoritative solver state, typed identity/generation and property composition rules.
Inventory current timer arrays, animation arrays, body hierarchy and transaction participants;
reuse their specialized implementations. This row changes design and ownership inspection tooling,
not production execution. P0-005 owns wire encoding, P0-006 clocks, P0-007 portable geometry,
P0-008 construction compilation; later P0 rows implement and qualify this contract.
ECS selection/adoption/experiments remain deferred.

Finite authored boundary: the actual production Compile items, including linked web bootstrap,
with separate Release and PLAYTEST compilations. There are 331 authored production C# inputs and
4,386 source members, including two indexers and 72 conservative primary-constructor captures.
Actual test Compile items include linked audit files, package-provided source and generated build
inputs; directory enumeration is not the closure. MSBuild rebuilds capture compiler-generated
bindings separately for each of the four production/test configurations. Context records retain
actual assembly/friend identity, language version, nullable/unsafe/overflow/output settings,
defines, source paths and reference paths/hashes. Production and test semantics never share a
synthetic combined assembly. Generated sources are used, not hand-authored replacement stubs.

Every declared field, property/indexer, event and positional record property is included, with
readonly references, get-only collections, static caches and checkpoint storage. Primary-constructor
parameters are conservatively included whether or not the compiler retains them. Constants have no
mutable storage. Auto-property backing state is represented by its property. Ordinary scratch is
invocation-owned; escaping delegates/iterators retain their actual owner's lifetime as detailed in
[the mixed-type transformations](assemblies.md#concrete-mixed-type-transformations).

The current generated JSON contexts contain mutable metadata caches/default instances. They belong
to the browser's construction save/diagnostics serialization context, with that context's lifetime;
they are not simulation state or a worker protocol codec. Generated Godot StringName metadata,
signal/property dispatch plumbing and inherited engine resources belong to the browser object/type
registry. Current source-generated methods participate in the caller context; these grouped generated
owners are not additional authored solver stores. Framework/package test fixtures own their local
test host state. Their source/reference identities and effects are retained for binding analysis,
not promoted to production gameplay ownership.

All production declaration identities are compiler documentation IDs, not simple names. Member uses
and indexers are compiler-resolved in their actual contexts; diagnostics must be zero for an audit.
The caller record additionally retains named calls, method groups and explicit virtual/interface/
delegate/external dispatch categories. Conservative dispatch sets, reference aliases and generated
effects are bounded in [the analysis contract](analysis-bounds.md). A direct source use is not a
proof of a complete runtime call trace, worker isolation or thread safety.
