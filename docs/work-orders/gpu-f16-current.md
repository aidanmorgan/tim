# Current WASM SIMD / IEEE-754 f32 contract crosswalk

Owner decisions explicitly replace wide game-value/CPU physical authority and compute shader physics with [canonical IEEE-754 f32 game values and WebAssembly SIMD physics numerical authority](../gpu-f16-physics.md). Canonical f32 extends across editor, content, saves, animation/read models, protocol and fixtures. Instanced presentation batches (`gl.drawElementsInstanced` in WebGL 2, `renderPass.drawIndexed` in WebGPU) eliminate compute shader constraints, and a lock-free zero-copy triple-buffered pose ring in `SharedArrayBuffer` eliminates GPU-to-CPU readback stalls. This is a current addendum; frozen original contracts, reviews, captured snapshots and failed/successful runs remain unchanged historical evidence.

Read this addendum before any affected original contract or historical source. A historic CPU/double Pass or WGSL compute spike is not current WASM SIMD f32 qualification. Every changed runtime/content input must be requalified at its existing stage; this design review itself closes no runtime row.
