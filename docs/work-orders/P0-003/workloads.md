## Common geometry and recipe

Generic fixtures use a visible 16×10 m deck with its upper surface y=0, represented by one static box body, half extents (8,.1,5), center (0,-.1,0). Unlike the retained First-principles workbench's two children, this named generic deck contributes one body/child. Gravity (0,-9.81,0), double authority, fixed 120Hz ticks, each split into four 1/480s outer substeps, initially resting bodies unless specified. Default sphere: radius .34, mass1, restitution .55, friction .3, zero aerodynamic drag/buoyancy for the isolated mechanical fixtures. Friction/restitution apply equally to deck. Explicit declaration order is row-major by z then x then y; reversing declaration order is the native control, not a browser placement shortcut.

Open the generic fixture construction surface, select the primitive from the normal palette and place each listed instance with handles. Use visible parameter controls for the specified non-position values; connect only the listed typed ports using ordinary link tools. Verify count/geometry/parameters from the accepted read bridge. Save, Run, observe the declared result, Reset, compare exact construction and links, then Load and compare exact saved construction. Keep failed placements/actions. Camera stays fixed at the normal overview with all instances in view for visible variants; offscreen variants use the normal camera controls, never disable authority. Capture CSS1440×900/DPR1 on desktop comparison runs, and native viewport/render scale on device qualification.

All timeout fixtures are authored without a winning objective; this does not disable an existing goal or change Workshop's 3600-tick limit. Existing goal fixtures retain their goals. The generic authored fixture controls are a concrete prerequisite; they are not a hidden benchmark mode.

## Mixed-domain cells and scaling

Each cell is one UI-placeable generic declaration assembly with typed ports and finite stores. The mixed deck is one static box centered (0,-.1,0), half extents (9,.1,9); it replaces the smaller common deck for these scenes. For receiver index r=0…R-1, cell origin is (-7+2(r mod 8),0,-7+2 floor(r/8)); R=1 uses origin (0,0,0). Source s=0…S-1 has a non-colliding marker at (-7.5+s,1,-10). The construction region is exactly x[-9,9], y[0,4], z[-11,9]. ENGINE-FIXTURE-UI must expose ordinary pan/placement throughout this region; no hidden population injection.

Within each cell the receiver housing is a static cube of side .1m at origin+(0,1,0). Electrical rotor center is origin+(-.5,1,0), local axis Z; its hinge connects to the deck at that center. Optical sink housing is origin+(.5,1,0). Pressure piston/occluder starts at origin+(-.4,1,0), moves along +Y over .5m; the probe ray runs from origin+(-1,1.25,0) to the receiver at origin+(.4,1.25,0), so the moving occluder crosses it. Radiation gate center is origin+(.5,1,0), hinge axis Y. A blocked optical/radiation control places a static absorber box at the midpoint of its source→receiver segment, local Z aligned to the segment, half extents (.25,.25,.02); each blocked branch has its own blocker. All omitted initial velocities are zero; housing and deck are static; rotor/piston/gate masses are as declared below.

Electrical and pressure links have ideal connection geometry (no path resistance beyond declared device law). Optical emitters have one directed branch per associated receiver with equal conserved power share; branch endpoints are the source marker and receiver center. These are generic multiport source declarations with a shared finite store, not independent energy sources. For pressure probe rays, the emitting port location is the per-cell point above; all branches belonging to a source share that source's finite probe store. Radiation is isotropic at the source marker. Each receiver is one fixed planar .01m² sensing area with normal pointing toward its round-robin assigned source; it never rotates separately for other sources. The overlapping-source child uses projected area A×max(0,n·u) for each source direction u and sums independently conserved contributions. Path lengths and attenuation are derived from these exact positions, never selected from measured outcomes.

For each source with k associated receivers, multiply its single-cell maximum power and initial energy by k, keeping per-receiver offered supply fixed across scaling. For overlapping S=16/R=64, k=4 for capacity accounting while each source samples all 64 receivers; total offered source power equals the non-overlapping case. Receiver/path work grows without multiplying total supply. This explicit scaling replaces any assumption of unlimited source capacity.
