### Constitutive contract and conserved incidence

At an exposed sample, let a be signed dot(source axis, current hinge axis), u>0 source speed, c the existing weighted pressure-scaled branch conductance, and v the sample-frame speed relative to the nozzle along the flow axis. A candidate pitch p adds p·a·ω to that relative speed. The branch uses the existing nonnegative capped slip force c·max(u−v−p·a·ω,0), with the existing common source force/power and joule allocation, not an independently powered torque. Applied angular effort is p·a times that same accepted force.

Its mechanical row is the existing point-force pair on sampling-frame/nozzle plus p·a times the exact hinge coordinate row (equal/opposite rotor/support torques). Merge repeated body incidence, include the nozzle's complete offset moment, and use the SAME row for velocity, work, application, component joining and feasibility. Thus source work u·impulse pays the full paired mechanical work plus nonnegative loss. The stationary support supplies axial reaction; a free support gets it physically. This reuses the generic multi-body ImpulseJacobian, not a hidden torque adder.

Preparation evaluates the signed net exposed rest force R0 using the same admitted branch caps/availability; nonpayable/disabled sources do not influence it. If |R0|<cut-in, no rotary supply branch is active and b=pmax/g provides passive relative damping. Edge-on and exact opposing R0=0 are passive. Otherwise desired Ω=clamp(g·R0,−Ωmax,+Ωmax). For active nonzero R0, compute Ω from the SAME frozen candidate exposure/velocity/supply state and define H(p)=sign(Ω)·R(p,Ω), with H(0)>0. Select pmax if H stays positive through pmax; otherwise select the FIRST boundary of that connected positive interval starting at p=0. H=0 is the upper root bracket even across a zero plateau, not permission to select its far edge. Retain b=p·R(p,Ω)/Ω≥0. R is the signed sum of the same capped branch forces evaluated at that trial shaft speed. This is one bounded same-law scalar search, not a negative-damping-only trigger or a fallback equation. At zero relative frame motion and one unsaturated source, this reduces to Ω=p·c·u/(c·p²+b).

Source reservation coefficients, caps and calibration must refer to the same candidate exposure/supply state: prepare after availability and joint source allocation are known. Freeze poses, axes, sample velocities, target and allocation coefficients throughout each scalar search. A changed outer trial allocation recalibrates from its new frozen state; it never carries old p/b or pays a force different from the calibrated row. Under fixed nonnegative coefficients, each signed uncapped contribution to H has derivative −|Ω|·c·a² with respect to p; clipping/capping adds flat segments. Moving offsets and opposing alignments therefore preserve this scalar monotonicity. This does NOT claim monotonicity or convergence of the full coupled allocation/physics solve.
