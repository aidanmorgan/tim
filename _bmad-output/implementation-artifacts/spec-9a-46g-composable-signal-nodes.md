## Design Notes

### Eight design answers

1. **Behavior:** declaration-only composition of existing signal primitives, under the story/requirement IDs and acceptance above. No new signal operation or scheduler.
2. **Reusable contracts:** existing contact, orientation, passage, contact-load, timer, indicator, oscillator, count and reset-dominant memory laws. Kinds/terminals/policies are closed enums; local identities are typed IDs. The necessary fixes restore distinct occurrence counting, causal delayed thresholds, representation-safe saturation and source-level deduplication.
3. **Data:** `SignalNodeId(string)` in base Abstractions, validated like other package-local IDs; `SignalEndpoint(Node, SignalTerminal)` with Input/Set/Reset/Output; typed edges and `SignalPortBinding(PortId, Endpoint)`. `ISignalElement` exposes SignalNodes/SignalEdges/SignalPorts (distinct from its inherited public Ports); the bundle SignalPayload stores Nodes/Edges/Ports. Abstract data-only node record plus sealed operation records, closed enum derived from the record, no nullable operation bag/callback. Use existing `ParameterId` for references. Existing source-generated JSON registers supported variants and one boundary discriminator; missing/unknown kinds/configuration, null entries and removed singleton properties refuse.
4. **Execution:** strict package/bundle admission → instance parameter resolution and stable local-name lookup → independent compiled node/sensor allocation → combined graph admission → existing scheduled/physical occurrence routing and committed state → exact read/event/presentation binding. Authoring uses a focused resolver without recursively invoking construction validation; worker admission uses the same resolved-graph topology validator.
5. **Ownership:** Simulation owns state, events and passage cursors. Logical owner is distinct from compiled node/body/sensor. Main thread owns authored construction and exact bindings; cosmetics only observe. Validate complete candidates before installation; Reset clears each node and source cursor while restoring authored fields. Save retains current declarations/connections; no runtime-state migration.
6. **Generality:** unfamiliar composed package, repeated same-kind nodes/roles, reordered declarations, same local names across owners, bodyless logic, dynamic child reference, shared supply route, exact selected contact/presentation and every control/boundary above. Planned proof is not existing executed evidence.
7. **Deletion:** nine singleton capability interfaces/payload members, exclusive compiler chain, owner-as-node allocation, unique-owner runtime guard, singleton sensor handles, owner-only Memory/GetCounterTarget/StateLatchPhase/ContactClosed and signal event/read selection. Remove unused SignalTriggerDescriptor/Mode/Triggers after verifying no live law caller. No aliases/overloads preserving old callers.
8. **Uncertainty:** required design choices are specified below; independent planning audit may identify a concrete gap. Implementation is active; current verification milestones are below and no final acceptance is claimed.

### Exact bindings and one graph rule

Every public signal port has one exact terminal binding; internal nodes need no public ports. Terminal direction/type derives from the operation contract, independently of public role identity. Source-only nodes refuse incoming edges; indicators refuse outgoing edges. Timers consume pulses; memory Set/Reset consume pulses. A rearming timer with no elapsed signal has no output terminal. An indicator follows its one level source or retains its first pulse under existing semantics.

The forward-only alias prohibition concerns legacy/old-name compatibility. Several current public ports may explicitly expose one supported endpoint; they are current declarations, not a legacy reader. Literal duplicate internal entries/authored connections refuse. Distinct public aliases may expose one terminal: resolve all edges to a SET of exact source-node/output → target-node/input deliveries. Cardinality, compatibility and cycle checks apply to that canonical set; compiled wire stores canonical edges and refuses duplicate rows. Pulse fan-in/fan-out remain supported; an input fed by a level takes exactly that one source. Same-owner public Activation links between distinct nodes are valid; other domains' owner restrictions remain unchanged.

Use one signal-specific topology validator, not a universal graph platform. For instantaneous-cycle detection, remove outgoing dependencies of positive-duration timers and reject remaining directed cycles. Counter and memory are not finite-time delays. Retain exact node self-edge refusal and existing finite one-shot timer feedback. Reuse scheduled → physical → consume ordering, timestamp/emitter queue order and aggregated reset-dominant latch requests; no second execution path.

Enforce genuine law restrictions, not element recipes. Resolve initial child poses through current compiled bodies, never root rotation.
