## Intent

**Problem:** Three presentation paths still bypass the declared binding path delivered by 4.1/4.2: the Receiver capture halo (`BasketPart.ApplyHalo` plus a `WorkshopPartKind.Receiver` special case in `MachineWorld.Gpu.cs`), the goal "SOLVED!" label alpha in `ui/WorkshopPuzzle.cs`, and the hint reveal in `ui/WorkshopAnimation.cs`, each with its own client pump, receive branch and `IWorkshopClient` members. Fourteen uncompiled legacy evaluator files remain under `engine/presentation/` and `ui/`.

**Approach:** Make the Receiver halo a declared `Capture` cosmetic curve on the shared part path, make goal and hint declared UI bindings on the same worker sample path with one generic UI apply loop, collapse `IWorkshopClient` to the unified frame calls, and delete every uncompiled presentation evaluator. The renderer then consumes only the pose ring and the animation worker channel.

## Boundaries & Constraints

**Always:**
- One cosmetic path for parts and UI: committed read → declaration-driven pump → worker → sample → generic apply (`MachinePart.ApplyCosmetic` for parts; a Control-target binding for UI). No per-target `Try*` methods, no `is BasketPart` / `WorkshopPartKind.Receiver` presentation branches, no direct `Modulate`/`Color.Lerp` writes outside the binding writers.
- Every pump honours the single animation lease (`_animationPending`) like 4.2's pumps; the hint path must not throw while the lease is busy (deferred-work item 1).
- Keep `CCGOAL_SOLVED` console emission on goal solve (e2e driver counts it) and the hint button behaviour (reveal, hide, visibility).
- Exact Reset: halo, goal label and hint return to neutral; Save/Load re-animates the halo on re-solve.
- Delete the uncompiled legacy files listed in the Code Map in this slice; update `docs/presentation-bindings.md` and `docs/simulation-presentation-bridge.md` to drop dangling class names; update `tools/e2e/anim-1a.test.ts` assertions to the new halo target/property.
- Closed sets stay enums; new feedback source and UI target identities are typed.

**Never:**
- Change physics, the physics wire, save format or persisted construction fields.
- Delete or edit uncompiled `parts/*`, `engine/ScenePhysicsAssembly.cs`, `engine/BodySlot.cs`, uncompiled tests, `ui/PlaytestConstruction.cs`, `ui/PlaytestDiagnostics.cs` or `tools/Ownership` (Epic 7 scope).
- Add a second evaluator, timer or lerp on the main thread, or a lease-bypassing send.
