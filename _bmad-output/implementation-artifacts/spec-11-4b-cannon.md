### Capability contracts and causal order

**Reservoir:** capacity C ≥ 0 J, initial E0 in [0,C], maximum charging demand P ≥ 0 W, exact identity; all finite. Generic bounds are physical validity/representation, not Cannon's 1–100 product ranges. Store E, cumulative accepted supply, release and dissipation independently. Accepted supply is min(C−E, routed available power × dt, declared charge demand × dt); clipping is not delivered work. No supply means zero charging, never erased charge. Separate contact-triggered discharge declares its own target speed/threshold/cooldown and store reference. Its existing Bumper behavior remains; no duplicate store per target.

**Chamber region:** finite cylinder in an exact body's current solved local frame, axial unit direction, half-length/radius, target set, width limits, containment allowance and relative-speed threshold. Count distinct dynamic bodies whose actual material intersects the finite region; a hollow gap alone is not occupancy. Multiple children count once. Full seating requires every participating collider child's material inside cylindrical caps and radial boundary, both aggregate transverse support widths within inclusive limits, and COM velocity relative to carrier velocity at payload COM within threshold. Partial child occupancy is detected; arbitrary child order has no effect. Declare region enabled/participation explicitly; disabling its associated functional collider makes it Empty. Reads distinguish Empty, Loading, Seated, Ambiguous and Departing using typed states.

**Cannon controls:** radius .48 m, half-length .55 m; both transverse widths [.6,.84] m; seating allowance .001f m and relative speed ≤1f m/s; sweep padding .02f m. These are authored admission features, not test epsilons. A 1 mm boundary allowance permits seated contact without accepting a visibly protruding payload or consuming the minimum .06 m radial margin of a centered maximum-width spherical payload; compound radial support still checks corners, not width alone. At the slowest admitted committed simulation tick profile (60 Hz), a 1 m/s relative load moves at most 16.7 mm, below that radial margin; a fast passing body must wait to settle. The 20 mm exit pad requires the rear support to clear the muzzle and its immediate exterior, so an adjacent thin obstruction cannot be treated as already behind the payload. The canonical default remains 120 Hz simulation with 480 Hz physical substeps and independent 60 Hz animation. `CuriousContraptions.Abstractions/CadenceValues.cs:49–73` admits 60/120/240 Hz simulation profiles with 8/4/2 physical substeps; the 16.7 mm calculation is a conservative admitted-profile bound, not animation timing. Freeze these values before implementation; do not tune against observations. Bowling width .56 is deliberately Unseated under the explicit .6 minimum; no identity exception. Future Tennis eligibility derives from actual geometry.

**Clearance:** translate the complete candidate body, at current orientation, along current region axis by max(0, halfLength + padding − rearSupport). Query continuous material intersection against every participating world collider except explicitly named frame body and payload; all its children are included. Hollow bores remain openings, not convex solid hulls. Obstacles attached to other bodies of the same element are not silently excluded. No coarse sampling that can miss the retained thin wall. Geometry outside supported query validity is typed refusal before any debit; all currently admitted shapes used by current consumers must be supported, not silently ignored.

**Request and evaluation:** a signal pulse carries exact actuator target and epoch. Coalesce duplicates targeting that actuator for the next physical boundary; retain pending request through Pause, consume on Step/Resume, clear on Reset/replacement. Evaluate current geometry at that boundary, before the following integration; arrival completed by that boundary qualifies, later arrival does not. Charge from the preceding completed interval is available; no credit for a future interval. Rejected requests never persist for later charge/loading. Precedence: disabled/zero occupancy Empty; prior departing body still overlapping Busy; multiple bodies Ambiguous; invalid size/containment/speed Unseated; incomplete charge Uncharged; blocked sweep Obstructed; cap reached SpeedLimited; zero admissible coupled response NoResponse; otherwise Fired. No accepted release becomes a second request via its own output. Last result persists until another request or Reset; departure state clears after full exit, allowing gravity return.

**Constrained actuator:** exact store, region, frame and target references; release axis from solved frame; target relative axial speed in m/s, here 12. Apply a center-of-mass axial effort to target with equal opposite frame reaction (static frame absorbs reaction); solve actual joints, unilateral contacts/friction and moving carrier response. Use the shared constrained trial/work-window machinery, adding a generic instantaneous actuator row at the fixed admission pose; adjust accepted effort within finite work/cap and commit one feasible response. Measure source work from accepted effort against midpoint relative endpoint velocity, accounting for carrier translation/rotation and all coupled constraints; account passive dissipation separately. Do not infer work from target mass or subtract arbitrary baseline kinetic energy. All trials restore constraint impulses and channel accounting as well as body state. No position integration/teleport during this transaction; ordinary substeps move bodies afterwards. A free scalar analytic result is a test oracle, never an alternate runtime branch. Zero feasible positive response retains energy and emits no release. Numerical residuals constrain or reject the candidate request, never fault the tick.

The world-owned typed transaction is also legal at the installed world's Idle transaction boundary, with valid owned dynamic targets and no concurrent step. This is a solver/application boundary, not permission to invent scene-level AddImpulse or insert a ball after Run. Public Workshop trigger path remains its declared next-boundary request. Wrong phase, foreign/stale target or reentrancy leaves all state unchanged. Fixtures author topology and initial conditions before Start.

**Commit/read/animation:** discharge event names actuator/store/payload and actual debit with typed phase/time. Store, result, count, departure, reactions and event publish atomically with the tick; failed candidate exposes none. No fixed cosmetic queue limits physics. Existing demand-grown event/animation retention handles occurrences; consumer lapping is explicit under current ring contract. Ordinary failed installation and pending request lifecycle run now; injected failed-tick stress remains at P0-032, with transactional design preserved now.

Package maps generic observation values to Empty/Loading/Charging/Ready/Firing/Jammed presentation; shared physics does not select those product colors. Firing is departing, Jammed is ambiguous or obstructed, otherwise Empty/Loading/Charging/Ready follows chamber/fullness. Store fraction targets charge-bar scale max(.001,E/C); ready flag 0 or −70°; state colors slate #556573, cyan #66b8c9, gold #f7cb52. Recoil cannot move colliders or drain stores; Reset clears it. Extend a bounded typed mapping where six states require it; never encode state through arbitrary floats/scripts.
