## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|---|---|---|---|
| Extend/retract | Supplied, exactly one command | Bounded movement to the selected endpoint; actual head pushes contacted cargo; absent cargo remains a meaningful control | No error |
| Hold | Neither command, both commands, or loss of supply during travel | Ideal self-lock at current coordinate, truthful holding/conflict/unpowered state, no motor work while locked; resume can move again | No error |
| Endpoint | Supplied lower/upper endpoint reached | Correct separate endpoint route visible next electrical tick; removing supply removes output | No error |
| Load/obstruction | Low-force vertical load, pinned cargo, or physical rod contact | Effort/work bounds; no created energy, cargo teleportation or obstruction penetration; blocked state distinct from endpoint | No error |
| Geometry/query | Extension/retraction, rotated mount, ray/body at rod midspan or adjacent miss | Physical and visible finite shaft agree; no stale collision after retracting | No error |
| Wiring/parameters | One supply feeding power and command, independent commands, parameter range edges | Valid declarations admitted; actual supplied routes determine behavior | Undefined enums, nonfinite/out-of-range values, missing/wrong/duplicate refs and conflicting writers refused atomically |
| Lifecycle | Run/Pause/Step/Resume, Reset and construction save/load | Correct supported commands, committed observations, exact authored Reset and semantic replay; work reset | Failed installation retains prior world |
