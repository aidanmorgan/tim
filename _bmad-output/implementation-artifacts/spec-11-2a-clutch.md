## Intent

**Problem:** CAT-018 Clutch (Story 11.2a, the first child of the split Story 11.2 aggregate) does not exist, and the generic `MechanicalTransmission` capability currently compiles only external port wires with unconditional engagement, no first-class world buffer table or supply gating, and no committed closure/phase observation.

**Approach:**
1. Promote `MechanicalTransmission` to a first-class reusable runtime capability (zero element-specific code in engine/core/bundle):
   - Add package-owned `IMechanicalTransmissionElement` (`IReadOnlyList<MechanicalTransmissionDescriptor>`) with optional `MechanicalValue? CloseSeconds`.
   - Extend `SupplyTarget` / `SupplyConsumer` with `SupplyTransmissionTarget(LocalMechanicalTransmissionId)` -> `SupplyConsumerKind.MechanicalTransmission(MechanicalTransmissionId)`, wired to its own explicit `bool[] Transmissions` / `TransmissionClosed` supply vector on `SupplyResolution` & `PhysicsTickInputs` (separate from actuator drive slots, so `RevoluteDrive` and `MechanicalTransmission` compose freely with zero D1/D2 aliasing).
   - Give `MechanicalTransmissions` its own first-class ABI table in `PhysicsWorldLayout` / `PhysicsGpuAbi` (`HeaderMechanicalTransmissionCountOffset = 140`, `HeaderPaddingOffset = 144`, `HeaderBytes = 160`, `MechanicalTransmissionBytes = 48`): `Id`, `Owner` (`NoBody` for external links), `DrivingSlot`, `DrivenSlot`, `Ratio`, `CloseSeconds`, committed `Supplied`, committed `Closure`, committed `Phase`, trailing zero padding (`40..47`). Delete superseded `AdmissionTransmissions` on `PhysicsTickInputs` and `transmissions` constructor arg on `WorkshopPhysicsEngine` (forward-only D5).
   - Untimed transmissions (`CloseSeconds == 0f`) admit with `Closure = 1f, Phase = Engaged, Supplied = false` and stay `Engaged` every tick. Timed transmissions (`CloseSeconds in [1/1024, 60] s`, requiring `Owner != default`) admit with `Closure = 0f, Phase = Open, Supplied = false`.
   - Advance timed transmissions once per tick before substeps: step `Closure` linearly by `± tickSeconds / CloseSeconds`, apply **directional** endpoint snap (`closure >= 1f - 1e-5f` -> `1f` when supplied; `closure <= 1e-5f` -> `0f` when unsupplied), derive `Phase` (`Open` at `0f`, `Engaged` at `1f` when supplied, `Closing` when supplied and `< 1f`, `Opening` when unsupplied and `> 0f`), engage constraint rows in `MechanicalTransmissionSolver.Prepare` strictly when `Phase == Engaged`, drop coupling immediately on supply loss while opening plates linearly, and expose committed `Closure` and `Phase` via `PhysicsPresentationRead.Transmissions` and `PresentationDriver.CommittedTransmissionClosure` / `CommittedTransmissionPhase` for all package-owned (`Owner != default`) transmissions.
2. Add `elements/Clutch/` as pure declaration data, art and visual bindings on top of `IHingeElement`, `IMechanicalTransmissionElement`, `ISupplyElement`, and `ISceneGeometryElement`.
